# The server Pokédex

Every species on the server — 2,367 of them — with their forms, Megas, stats, abilities,
learnsets and evolution chains, plus a 3D model you can spin. Built straight from the
merged datapack, so it says exactly what the game loads.

Plain static files. No build step, no framework, no CDN. Drop the folder on any web host,
or open it through a local server.

---

## 1. Get the models

The site ships without pictures, because the models and textures live in the packs you
already have and there is no sense shipping them twice. One command puts them in:

```
python build-assets.py --from ..\merged --from ..\Cobblemon-neoforge-1.8.0+1.21.1.jar --from ..\mega_showdown-neoforge-1.0.2+1.8+1.21.1-release.jar
```

All three matter. `..\merged` has everything the addons add — and because the script now
opens `.jar` files at any depth, that one path also covers `merged\mods\`, where the
Megas and several hundred other models live. Cobblemon's jar has the 1,025 official
Pokémon. Mega Showdown's jar has the Mega and Gigantamax models.

**If you ran an older copy of this script, re-run it with all three.** It used to only
open archives sitting at the top of a folder, so every model inside `merged\mods\` was
invisible to it — that alone was most of the "no model" placeholders. With all three
sources it finds a model for 2,366 of the 2,367 species and writes about 120 MB into
`models/`. It takes under a minute.

Until you run it, every page shows a placeholder where the model would be. Everything
else works.

## 2. Look at it

Any static server will do:

```
python -m http.server 8080
```

then open <http://localhost:8080>. Opening `index.html` by double-clicking will **not**
work — browsers refuse `fetch()` on `file://` URLs, so the data never loads.

To put it online, upload the whole folder as-is. It is all static; there is nothing to
configure.

## Setting where things are found

`data/locations.json` is yours. The site reads it at load time, so you can edit it and
refresh — no rebuild, no restart.

```json
{
  "locations": {
    "bulbasaur": ["Route 1", "Verdant Cave"],
    "cottonee":  ["Meadow Path"]
  }
}
```

The key is the species id as it appears in the page's URL — lowercase, no punctuation, so
`#/p/mrmime` is `mrmime`. A species with no entry says "No location set yet." rather than
guessing from biomes, since Cobblezones is deciding that, not the datapack.

## Refreshing after a pack change

`build-assets.py` is the only script here you need to run, and only when models or
textures change:

```
python build-assets.py --from ..\merged --from ..\Cobblemon-neoforge-1.8.0+1.21.1.jar --from ..\mega_showdown-neoforge-1.0.2+1.8+1.21.1-release.jar
```

The species data under `data/` is generated by the merger, not by this folder — if the
merged pack changes (a new addon, a different conflict decision), ask for a rebuilt
`data/` and drop it in. `data/locations.json` is never overwritten by either.

## If a rebuild doesn't show up

It will. Every data file is fetched with a build id that changes each time the Pokédex is
rebuilt, so the browser can't serve you yesterday's copy. If you are on an older build of
this folder and the pages look stale, one hard refresh (Ctrl+F5) clears it for good.

## If Python complains about an encoding

Everything here is UTF-8. The script sets that explicitly, so a `UnicodeDecodeError`
means you are on an older copy — re-extract the zip.

## What's in a page

- **Model** — the real Cobblemon geometry, rotatable, one per form. Drag to turn, scroll
  to zoom, Pause to stop the slow spin.
- **Forms** — every form the merged pack gives that species, Megas marked, battle-only
  forms marked. Switching form switches the model, stats, abilities and typing.
- **Stats** — the form's own, with the total.
- **Abilities** — with what each one actually does, pulled from the battle data. Hidden
  abilities marked.
- **Where to find it** — from `locations.json`.
- **Evolution** — what it comes from, what it becomes, and the condition in words
  ("level 32", "use Fire Stone", "friendship 220+, at day").
- **Details** — egg groups, gender ratio, catch rate, EV yield, EXP group, height, weight.
- **Moves** — level-up, TM, egg, tutor and legacy, each with type, category, power,
  accuracy, PP and effect.

## Known rough edges

**Models stand in their real pose now.** Cobblemon authors its geometry with the limbs laid
out flat and puts them in place at runtime with a poser written in Molang, a little
expression language. This used to read only the plain numbers and count every expression
as zero — which threw the pose away, because the pose is *inside* the expression:
Charizard's wing is `-55+math.sin(q.anim_time*90*0.7-60)*8`, fifty-five degrees of wing
plus a small flap. There is a Molang evaluator in `build-assets.py` now, so each bone is
read at the animation's first frame. That put 147,649 bone channels across 1,498 species
into the pose they hold in game: Charizard's tail curls and its wings fold, Gyarados
coils, Empoleon's flippers sit out from its body.

Cobblemon writes the posers for a good part of the older dex in Kotlin rather than JSON —
Vivillon is one, which is why its wings hung folded and edge-on. Where there is no poser
file to read, the model's own idle animation is read directly instead. Between the two,
10,808 of 11,562 model entries are posed.

What is still missing is motion and anything the game decides at runtime — a Pokémon that
turns to look at you, or blinks. The models here hold one frame and spin.

**The prop-like oddities are gone from the dex.** UFO, Monster, Humanoid, Majin,
Transport, Whitedoor, Brycen-man, Blackdoor and 26 unfinished beta mons were all sharing
one stand-in model between them, so they were de-listed rather than shown.

**Species with no model at all are no longer listed.** Seventy-eight of them had no model in any
pack, so they were taken out of both this site and the in-game Pokédex rather than shown
as blank pages. The species themselves still exist and still work — add a model and they
come straight back. `reports/delist_log.jsonl` lists every one and why.

**If you had models that looked like the wrong Pokémon, that is fixed.** Models used to be
looked up by the identifier written inside the geometry file, and those are not unique —
524 of them are claimed by more than one file here, and 432 files simply call themselves
`geometry.unknown`. Venusaur was being drawn as Corflora, Ivysaur with its female model,
and 1,693 entries in total had somebody else's geometry. The lookup now goes by filename,
which is what Cobblemon itself uses.

**Texture layers are drawn now.** A resolver can hang extra textures off a variation, each
painted over the model on its own pass — that is where Vivillon's wing patterns and Mega
Typhlosion's flames live. The main texture is transparent underneath them, so ignoring the
layers did not merely lose a detail: Vivillon had no wings at all. They ship as their own
files and the viewer stacks them on a canvas before uploading the texture. 5,470 of the
11,562 model entries have at least one.

Emissive layers come out lit-looking rather than actually glowing, which is as close as a
still page gets.

The build prints `model entries : … (… posed, … with texture layers)` when it finishes.
If that last number is ever 0, the layers did not make it and Vivillon has no wings.

**Shiny textures aren't wired to a toggle yet.** They are collected where they exist, so
adding the switch later is small.
